# Claude

## [One Take Studio](onetake/): edit your reels with Claude Code, no CapCut grind

Film like normal, drop your clips in a folder, and tell Claude Code
*"I have a new reel to edit."* Claude does the rough cut, captions, hook, looks
and music. Then it opens a studio in your browser where you review everything
live, swap anything, and ask Claude for new looks. One click renders it, and the
studio also makes a CapCut layer pack, a carousel, a story and three trial reels.

Setup and how to use it: [onetake/README.md](onetake/README.md)
